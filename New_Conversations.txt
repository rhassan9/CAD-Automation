To get the '1x8' and '1x8 to 1x4' sheets,
 
there's data in the 1x4 splitter blocks called AD_1 - AD_4. We run a lisp that populates these attributes with address data within the block.
 
Then we do an extraction file that pulls 1x8 and 1x4 data into an excel sheet where we then upload it to a 'master prompt' in an LLM
 
This output is used to catch final mistakes, copy and paste to fill out those two noted sheets; and then with all of the address data completed in the '1x8 to 1x4' sheet we have the ability to populate the house count sheet with data without manual entry.

=============

1x8 and 1x8 to 1x4 Master Prompt
You are filling two Lumos workbook sheets from an extraction file:

1) CABLE TO 1X8 SPLICING
2) SPLICING 1X8 TO 1X4 SPLITS

Your job is to read the extract carefully and produce workbook-ready data for those two sheets only.

IMPORTANT GOAL
Build the 1x8 and 1x4 sheets exactly the way Lumos expects them:
- Primary splitter naming must follow Lumos naming
- Secondary splitter naming must follow Lumos naming
- T-counts must follow the exact 1x8-port-to-1x4-range mapping
- Missing or unused 1x8 ports must show as SPARE
- Fiber order must follow the actual feeder/secondary position and remain color-for-color
- Do not invent ports, splitters, or addresses
- Do not “smooth over” mismatches silently; flag them

==================================================
SECTION 1 — LUMOS RULES TO FOLLOW
==================================================

A. 1X8 PRIMARY SPLITTER NAMING
Primary splitters are named from the feeder fiber / port feeding them.

Format:
OLT{OLT_NO}_{PLACEMENT_NO}P_{MARKET}

Example:
OLT09_32P_HLSPNC

The 1x8 output ports are written as:
{BASE_NAME}, {PORT_NO} ({BASE_NAME}-{PORT_NO})

Example:
OLT09_32P_HLSPNC, 4 (OLT09_32P_HLSPNC-4)

B. 1X4 SECONDARY SPLITTER NAMING
Secondary splitters are named from the 1x8 port feeding them.

Format:
OLT{OLT_NO}_{PLACEMENT_NO}P_{SECONDARY_NO}S_{MARKET}

Example:
OLT09_32P_7S_HLSPNC

C. T-COUNT / OUT COUNT MAPPING
Each 1x8 port maps to one 1x4 and one customer range:

Port 1 -> 1-4
Port 2 -> 5-8
Port 3 -> 9-12
Port 4 -> 13-16
Port 5 -> 17-20
Port 6 -> 21-24
Port 7 -> 25-28
Port 8 -> 29-32

D. SPARE RULE
If a 1x8 port is not actually used by a 1x4 in the extract, that 1x8 port must be SPARE.

For the 1x4 sheet:
- if an entire secondary position is unused, that row should be shown as spare
- do not create a fake 1x4 splitter name for a spare row

E. COLOR-FOR-COLOR / POSITION RULE
Fiber assignments must stay aligned with the actual feeder and secondary position.
Do not renumber secondaries just to make the sheet look full.
The actual 1x8 port / secondary number is the source of truth.

This means:
- if only ports 3-8 are used, ports 1-2 must remain SPARE
- if a row says it is secondary 6, it must stay secondary 6
- T-count must match that secondary number
- do not shift rows upward to remove gaps

F. LOWEST TO HIGHEST SECONDARY ORDER
On the 1x4 sheet, list the secondaries in order from 1 to 8, top to bottom.
That means 1-4 at the top and 29-32 at the bottom.

==================================================
SECTION 2 — WHAT TO READ FROM THE EXTRACT
==================================================

Use the extract as the only source of truth for:
- placement number
- placement address
- OLT number
- market code
- 1x4 splitter name if present
- split reference / pair count / source assignment
- servicing addresses
- whether a row is truly used or spare

If the extract has both FIBER_CO and PAIR_CNT or similar fields:
- use the secondary number implied by the split reference / feeder reference as the truth for position
- use the 1x4 splitter name field as the displayed 1x4 name only if it agrees with the secondary position
- if they disagree, flag the mismatch clearly

SECTION 6 — HOW TO HANDLE MISMATCHES
==================================================

If the extract is inconsistent, do this:

CASE A — Split reference says secondary 6, but 1x4 name says secondary 5
- use secondary 6 for position and T-count
- flag mismatch

CASE B — 1x8 placement exists but only secondaries 3, 4, 8 exist
- 1x8 sheet:
  port 1 = SPARE
  port 2 = SPARE
  port 3 = used
  port 4 = used
  port 5 = SPARE
  port 6 = SPARE
  port 7 = SPARE
  port 8 = used

- 1x4 sheet:
  rows 1, 2, 5, 6, 7 = SPARE
  rows 3, 4, 8 = used

CASE C — all 8 secondaries exist
- no spares
