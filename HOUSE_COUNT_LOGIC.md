# HOUSE COUNT - Logic & Formatting

The House Count sheet provides a master inventory of all premises serviced by the network. It is generated by aggregating all unique addresses found across the splitter sheets and applying specific engineering formatting.

## 1. Data Source & Extraction (Pipeline)
The script extracts every unique address found in the `SPLICING 1X8 TO 1X4 SPLITS` sheet (Columns E, F, G, and H).

### Data Cleaning Rules:
- **Upper Case**: Every address must be converted to `UPPER()`.
- **Unit Parsing**: If an address string contains '#' or 'UNIT', the part from that marker to the end must be moved to **Column E (Unit Number)**.
- **De-duplication**: Each unique address (after cleaning) must appear exactly once.
- **Sorting**: The final list must be sorted alphabetically by Column A (Full Address).

## 2. Column Mapping (A through K)
| Col | Name | Value / Source |
| :--- | :--- | :--- |
| **A** | **FULL ADDRESS** | Extracted Address (e.g. `4700 BENTCREEK DR`) |
| **B** | **CITY** | `FUQUAY-VARINA` |
| **C** | **STATE** | `NORTH CAROLINA` |
| **D** | **ZIP CODE** | `27526` |
| **E** | **Unit Number** | Extracted from address string (if present) |
| **F** | **HOUSE TYPE** | `RES-SFU` |
| **G** | **Drop Type** | `BURIED` |
| **H** | **Servicable (Y/N)** | `Y` |
| **I** | **Serviceability Notes** | *[Empty]* |
| **J** | **RES** | `1` |
| **K** | **BUS** | `0` |

## 3. Visual Formatting Requirements
To match the client's signature LLD look, the following styles are mandatory:

- **The "12-Row Frame" Rule**: Every 12 entries (Rows 13, 25, 37, 49, etc.) must have a **Thick Black Bottom Border** (Weight/Width: 2 or 3) applied across the entire range from Column A to Column K.
- **Global Borders**: All other data cells must have a Standard Thin Border on all four sides.
- **Alignment**: Every cell in the sheet (except headers) must be **Center Aligned** (both horizontally and vertically).
- **Fonts**: Calibri, Size 11.
- **Header Preservation**: Preserve the yellow background and custom filters in Row 1. Start writing data from Row 2.
